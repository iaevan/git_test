# Village Economy Sandbox

A single-file simulation (`index.html`, no dependencies) for designing a
farming-village economy before building the game. Open it in any browser.

- Place buildings (grocery, bakery, farmer's market, museum, tavern, houses, gate…)
- Program villagers: job + wage, outside income, demand (product × qty × weekdays), daily routine
- Travellers arrive from outside with cash, shop, sightsee, and leave
- Constant prices (v1). Full money accounting with a conservation check
- Stats, charts, unmet-demand reasons, transaction log, run comparison (pin runs)
- Setup autosaves in the browser; export/import as JSON

See the in-app **📖 Rules** tab for the exact rules.
