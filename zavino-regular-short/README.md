# regular. — a zavino. labs teaser (animated short)

The fourth film in the series, made with the **Shorts Animator** skill in the same **clean** look as *Meet Pixel* — but for a product that is **not built yet**. It says so: *"So we're building something at Zavino Labs"*, a *Work in progress* tag, a *Concept preview* label on every product screen, and a *Coming soon* end card.

**The product (working name `regular.`)** — smart review + customer tracking for restaurants and cafés: a QR code on every table earns a verified phone number (OTP), the order and the bill; then a private rating + Google review link, instant low-rating alerts, regulars / big spenders / lapsed customers, AI-written campaigns the owner approves (Eid, Ramadan, Pohela Boishakh), offer rules, and a monthly report. See [`IDEATION.md`](IDEATION.md) for positioning, naming, the concepts considered and the backlog.

**The story (≈59 s, 9:16, 37 shots)** — *Café 27* in Dhanmondi has 312 customers a week and the owner, **Nila**, knows none of them. Unhappy ones leave quietly and post one star. So zavino. labs is building something: **Rafi** scans a table QR, verifies his number, picks a chicken burger and a cold coffee, shows a one-time code, Nila types the ৳850 bill → a real, paying customer. An hour later: *how was it?* — five stars go to Google, two stars buzz Nila's phone while she can still fix it. Four visits later he's a **regular**; next time Nila greets him with *"The usual, Rafi?"*. Dashboards, AI campaign drafts (approve to send), offer results, a monthly report → **regular. — coming soon from Zavino Labs.**

## Rebuild

```bash
python3 tools/voice.py                       # download + trim the 16 narration clips
python3 tools/make_short.py                  # short.json
tools/build.sh                               # scenes.js
export CHROME=/path/to/chrome-headless-shell SHORTS_GL=swiftshader   # CPU painting in a container
node skill/scripts/animate.mjs frames .      # one frame per shot → frames/sheet.jpg
node skill/scripts/animate.mjs render .      # the MP4 (~15 min on 4 CPU cores in clean mode)
```

## Patches to the skill (in `skill/`)

* `scripts/lib/chrome.mjs` — `--no-sandbox --disable-dev-shm-usage --enable-unsafe-swiftshader` so headless Chrome runs as root in a container, painting in software.
* `scripts/runtime/stage.js` — `look.mode: "clean"` skips the brush pass; captions are rounded pills.
* `scripts/animate.mjs` — `voice.clips` (one pre-trimmed audio file per line), `cues` (sound effects placed by shot), and **web fonts**: any `assets/*.woff2` is registered as `@font-face` and loaded before the first drawing (used for Manrope).
